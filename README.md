# ChatBook · 微信聊天记录整理工具

把「我和某个好友的微信聊天记录」整理成**可阅读、可长期保存、可离线打开**的文档，并可选开启 AI 人物画像分析。

**纯本地运行 · 数据不出你的电脑（AI 功能可选且自控）· 不触碰微信客户端**

---

## 核心功能

| 功能 | 说明 |
|---|---|
| 📥 多格式导入 | 微信复制/导出文本、结构化 txt、JSON、CSV、HTML，拖拽或选择文件即可 |
| 📋 剪贴板监听 | 在微信里多选消息 `Cmd+C`，约 2 秒自动入库（适配 Mac 微信 4.x 复制格式），重复复制自动去重 |
| 🔍 全文搜索 | 内置全文索引，按关键词/发送人/类型/日期过滤 |
| 🖼 媒体关联 | 拖入图片/表情/视频文件夹，按时间戳自动关联到对应消息 |
| 📤 四种导出 | HTML 阅读器（类微信界面）/ 单文件 HTML（内嵌图片）/ Markdown / PDF |
| 🧠 AI 分析（可选） | 人物画像、重要信息提取、关系建议、回复草案，支持 DeepSeek / OpenAI 兼容 API / 本地 Ollama |
| 📝 便签与收藏 | 消息便签 + 手动便签墙，重要信息自动沉淀 |

## 隐私与安全

- **本地离线**：所有数据保存在 `~/Documents/ChatBook/`（SQLite + 媒体文件夹），不上传、不收集
- **不碰微信**：不模拟登录、不注入进程、不读取微信数据库——只处理**你自己复制/导出**的内容
- **剪贴板只在开启监听后读取**，且仅当内容形如微信复制格式时才处理
- **唯一联网场景**：你主动配置 LLM 并点击「分析」时，会把当前会话的**文本**发送到**你自己填写的** API 地址；配置本地 Ollama 则零外发。不配置 API Key 时全程零联网
- **彻底删除**：删除会话即连带清理消息、媒体、便签与留档；删除整个 `~/Documents/ChatBook/` 目录 = 数据归零

## 安装

### 方式一：直接使用安装包（macOS）

解压 zip（或挂载 dmg）→ 将 **ChatBook** 拖入「应用程序」→ 双击打开。

> 首次打开若提示"无法验证开发者"：右键点击应用 →「打开」→ 再点「打开」；或在「系统设置 → 隐私与安全性」中点「仍要打开」。

### 方式二：从源码构建（macOS，需 Node 18+）

```bash
git clone https://github.com/whitewolf3/wechat-chatbook.git
cd wechat-chatbook
npm install
npm run dev      # 开发模式直接运行
npm run dist     # 打包 dmg / zip（dist/ 目录）
```

## 快速上手（四步）

### 第 1 步 · 新建会话并导入

1. 点击左下角「＋ 导入聊天记录」
2. 选「新建会话」，填写：
   - **会话标题**（如「我和张三」）
   - **我的昵称**（聊天记录里你自己的显示名，用于区分左右气泡）
   - **对方昵称**（好友的显示名）
3. 拖入或选择**聊天数据文件**（支持 txt / json / csv / html / log）
4. （可选）拖入**媒体文件夹**——图片/表情/视频会按时间自动关联到消息
5. 同一批记录重复导入不会产生重复消息（自动去重）

### 第 2 步 · 聊天记录从哪来

**最省事：剪贴板监听（Mac 微信推荐）**

1. 打开会话后点击工具栏「📋 监听剪贴板」
2. 在微信聊天窗口**多选消息**（可跨屏连续多选）→ `Cmd+C`
3. 回到 ChatBook，约 2 秒自动入库；开监听前复制的最后一段也会补入库
4. 规则：消息里的发送者昵称须与该会话的「我的昵称/对方昵称」匹配，否则不入库（防误抓）

**手动整理文件**：从微信复制/导出的文本直接粘贴存为 `.txt`，或按 `examples/` 目录中的示例整理（结构化 txt / JSON / CSV / HTML）。

### 第 3 步 ·（可选）配置 AI 功能

不配置也能完整使用导入、搜索、导出功能。要开启 AI 分析：

1. 点击工具栏「🔑 LLM」按钮
2. 填入 API Key（推荐 [DeepSeek](https://platform.deepseek.com/api_keys)，几块钱够用很久；也支持 OpenAI 兼容接口 / 本地 Ollama）
3. 点「🔌 测试连接」确认可用 → 保存（**立即生效，无需重启**；Key 只存本机 `.env`，界面显示为脱敏形式）

配置后点击「✨ 分析人物画像」：全量分片分析 → 人物画像 / 重要信息 / 建议 / 回复草案。

### 第 4 步 · 导出

| 格式 | 用途 |
|---|---|
| 导出 HTML | 类微信阅读器（按日期分组、筛选、搜索、图片灯箱），适合日常翻看 |
| 导出单文件 | 图片 base64 内嵌为**一个** HTML 文件，适合归档/传给别人 |
| Markdown | 纯文本归档，适合笔记软件 |
| PDF | 打印或正式存档 |

## 常见问题

**Q：会把我的聊天记录传到网上吗？**
不会。除「你配置了 LLM 并主动点击分析」这一场景外（发送到你自己填的 API 地址），全程零联网。

**Q：会被微信封号吗？**
本工具不与微信通信、不模拟任何账号操作，只是读取你主动复制到剪贴板/导出的文本，不存在封号风险来源。

**Q：支持 Windows 吗？**
当前仅支持 macOS。

**Q：数据在哪个目录？怎么彻底删除？**
`~/Documents/ChatBook/`。在应用内删除会话即清理该会话全部数据；退出应用后删除整个 `ChatBook` 目录即彻底清零。

**Q：换了电脑怎么迁移？**
退出应用，拷贝整个 `~/Documents/ChatBook/` 目录到新电脑同位置即可。

**Q：重复导入同一段聊天会重复吗？**
不会。消息按「发送者+时间+内容」指纹两级去重，先导文字后补图片也会合并到同一条消息。

**Q：为什么有的消息显示 [图片] 占位？**
纯文本导入时无法携带图片。把聊天中的图片/视频存到文件夹后作为「媒体文件夹」再次导入（或拖入），会按拍摄时间自动关联。

**Q：API Key 填错了想换？**
「🔑 LLM」面板随时可改，保存立即生效；留空保存 = 保持不变，点「清空」= 删除 Key。

## 项目结构（开发者）

```
src/
├── main/               # Electron 主进程
│   ├── parsers/        # 六种聊天格式解析器（registry 多格式嗅探 + 宽松兜底）
│   ├── db/             # SQLite（better-sqlite3）：消息/便签/画像/FTS 全文索引
│   ├── import/         # 导入器 + 剪贴板监听（轮询 hash 变化）
│   ├── export/         # HTML / Markdown / PDF 导出器
│   ├── ai/             # 本地启发式画像 + LLM 深度分析（分片全量管线）
│   └── ipc.ts          # IPC 契约中心
├── preload/            # contextBridge 安全暴露
├── renderer/           # React 18 界面
└── shared/             # 跨进程类型契约
scripts/                # 无头测试套件（smoke 24 项 / 剪贴板 20 项 / bug 回归 22 项 / LLM 配置 29 项）
```

```bash
npm run smoke          # 冒烟测试（解析 → 去重 → 搜索 → 媒体关联 → 导出回读）
npm run typecheck      # TypeScript 全量类型检查
```
